Sobre o projeto

Git e GitHub
na prática.

Uma formação introdutória para estudantes e interessados em tecnologia que desejam aprender a organizar versões de arquivos, trabalhar com repositórios e colaborar em projetos de software.

01

Controle de versão

Entenda como registrar alterações, acompanhar o histórico e trabalhar com segurança usando Git.

02

GitHub

Aprenda a publicar repositórios, sincronizar arquivos e utilizar a plataforma para colaboração.

03

Trabalho em equipe

Pratique branches, pull requests e fluxos básicos de colaboração usados em projetos reais.

Conteúdo do curso

O que você
vai aprender?

O curso é organizado em quatro etapas progressivas, partindo dos fundamentos do Git até práticas de colaboração e integração com ferramentas de desenvolvimento.

01 Git

Fundamentos do Git

Controle de versão, instalação e configuração, repositórios locais, commits, histórico e boas práticas.

↗
02 GitHub

GitHub e colaboração

Conta no GitHub, repositórios remotos, sincronização, branches e introdução a pull requests.

↗
03 Ferramentas

Integração com ferramentas

Uso do Git em editores de código, Visual Studio Code, GitHub Desktop e fluxos colaborativos.

↗
04 Prática

Prática integradora e revisão

Aplicação dos conteúdos em uma atividade guiada, revisão, esclarecimento de dúvidas e avaliação final.

Antes de se inscrever

Crie sua conta de Extensão no SIGAA

Para realizar a inscrição, você precisa ter um cadastro na área pública de cursos e eventos de extensão do SIGAA. Se já possui esse cadastro, pode pular o tutorial e ir direto para a inscrição.

!
Já tem cadastro na Extensão?

Você não precisa criar outra conta. Vá direto para a seção de inscrição no final desta página.

Ir para inscrição ↓
01

Acesse a área pública do SIGAA

Abra a página pública do SIGAA do CEFET-MG. No menu, escolha Extensão e depois Acesso à Área de Inscritos em Cursos e Eventos.

Abrir área pública do SIGAA ↗
02

Escolha “Ainda não possuo cadastro”

Na tela de login da Extensão, clique nessa opção para iniciar a criação da sua conta.

Abrir tela de login ↗
03

Preencha o formulário

Informe os dados solicitados, preencha todos os campos obrigatórios, defina sua senha e clique em Cadastrar.

04

Confirme o cadastro por e-mail

Após o cadastro, o SIGAA enviará uma mensagem para o endereço informado. Abra o e-mail e clique no link de confirmação.

05

Entre na área de inscrições

Volte à tela de acesso, entre com o e-mail e a senha cadastrados e abra o menu Cursos e Eventos Abertos.

06

Localize o curso

Encontre o curso de Git e GitHub na lista de ações disponíveis. A partir daí, você estará pronto para concluir a inscrição.
